# 🎮 XO GAME

A simple and interactive **Tic Tac Toe game** built with **HTML, CSS, and JavaScript**.

## ✨ Features

* 🎯 Interactive 3×3 game board
* ❌ X and ⭕ O players
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔄 Restart the game
* 📱 Simple and clean interface

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns choosing an empty square.
3. The first player to complete a row, column, or diagonal wins.
4. If all squares are filled without a winner, the game ends in a draw.
5. Restart the game to play again.

No installation is required.

Simply open `index.html` in your browser and start playing.
